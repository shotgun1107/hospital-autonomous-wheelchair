# 3분 시연 시나리오 초안

> 팀과 시연 범위를 합의하기 위한 후보안이다. 시간표와 예외 장면은 확정되지 않았으며 구현 기준이 아니다. 현재 범위의 우선 기준은 [프로젝트 큰 틀 기준선](../../docs/product/big-picture.md)이다.

시연의 주인공은 환자 직접 호출이다. 의료진 예약은 두 번째 요청을 통해 목적지 도착 목표시각, 미시작 요청의 예약 기본 우선, 의료진의 순서 변경과 대기열을 짧게 보여준다.

## 환자 직접 호출 중심 종단 시연

| 시간 | 화면·동작 | 성공 기준 |
| --- | --- | --- |
| 0:00–0:10 | `축소 POC·실제 사람 탑승 금지`와 두 문제 제시 | 의료진 부담 감소와 환자 이동 자율성을 함께 설명 |
| 0:10–0:25 | 환자가 승차장 태블릿·키오스크에서 목적지 선택과 직접 호출 | 직접 호출 출처의 미션 ID 생성 |
| 0:25–0:35 | 한 대의 빈 휠체어 배정 | 대기 순번·예상 도착시간·목적지·승차 지점·진행 상태와 지도상의 예정 경로·의미적 위치 표시 |
| 0:35–0:55 | 빈 휠체어가 대기 위치에서 승차 지점으로 이동 | 원격 조향 없이 승차 정지 구역에 정지 |
| 0:55–1:07 | 인형 탑승과 고정 모형 QR 미션 확인 | QR 확인 전에는 목적지 운행을 시작하지 않음 |
| 1:07–1:22 | 목적지 방향으로 운행 | 동일 미션 ID와 의미적 위치 유지 |
| 1:22–1:35 | 진행 경로에 정적 장애물 배치 | 충돌 전에 먼저 무접촉 정지하고 정지 이유 표시 |
| 1:35–1:47 | 대체 이동 방법 판단과 화면 표시 | 기존 미션·목적지를 유지하며 새 이동 방향 표시 |
| 1:47–2:05 | 새로 선택하거나 수정한 경로로 목적지 이동 | 원격 조향 없이 장애물을 지나 목적지 도착 |
| 2:05–2:16 | 센서 하차 확인; 불확실 상황은 환자 `하차 완료` 버튼, 필요하면 의료진 확인으로 보완 | 하차 확인 전에는 자동 복귀하지 않고, 확인 후 운행 완료 표시 |
| 2:16–2:36 | 빈 휠체어의 대기 위치 자동 복귀 | 원격 조향 없이 대기 위치에 정지 |
| 2:36–2:52 | 의료진 예약과 추가 직접 호출을 함께 생성해 예약 기본 우선과 의료진의 순서 변경을 표시 | 선택되지 않은 요청은 대기열과 예상 대기시간 표시; 이미 탑승한 운행은 중단하지 않음 |
| 2:52–3:00 | 상태·시험 로그 요약 | 동일 미션 추적, 장애물 정지·대체 이동·자동 복귀 결과 표시 |

## 본편 밖 보조 검증 장면

아래 예외 흐름은 3분 본편에 모두 넣지 않고 짧은 별도 시험 영상이나 보고서 증거로 검증한다.

- 직접 호출 환자 부재: 시연용 10초 대기와 소리 알림 뒤 자동 복귀
- 의료진 예약 환자 부재: 의료진 보고 뒤 요청 종료와 자동 복귀
- 탑승 확인 전 환자 직접 호출·의료진 예약 취소: 다음 대기 요청이 있으면 해당 승차 지점으로 재배정하고, 없으면 대기 위치로 복귀
- 출발 전 배터리 조건 미달: 새 미션을 시작하지 않음
- 승객 운행 중 일반 저전력: 현재 목적지와 하차까지 마친 뒤 복귀하고 새 미션을 받지 않음
- 즉시 운행을 계속할 수 없는 임계 전원 문제: 일반 저전력과 구분해 안전정지
- 승객의 도움 요청: 즉시 정지, 현장 알림음·화면 표시와 의료진 웹 알림, 의료진 확인 전 자동 재출발 금지
- QR 불일치: 한 번의 불일치에도 목적지 운행 금지와 담당 의료진 웹 알림

## 촬영 원칙

- 호출, 빈 휠체어 이동, QR 확인, 목적지 운행, 장애물 대응과 자동 복귀를 가능한 한 연속 촬영한다.
- 출발·정지·장애물 대응 직전과 직후를 잘라 붙여 성공처럼 보이게 하지 않는다.
- 로봇 상태와 미션 ID를 화면 한쪽에 함께 표시한다.
- 외부에서 원격조종하지 않았다는 점이 드러나게 한다.
- 의료진 예약 화면보다 환자 직접 호출의 실제 물리 운행에 더 많은 시간을 배정한다.

## 아직 결정할 요소

- 최종 목적지 수
- 전체 대체 경로 선택과 제한적 현재 경로 수정 중 실제로 보여줄 방식
- 고정 모형 QR을 환자 쪽과 휠체어 쪽 중 어디에 둘지
- 센서 자동 하차 확인과 환자 버튼·의료진 확인 fallback을 영상에서 어떻게 구분해 보여줄지
- 의료진 예약·충돌 선택 화면을 실시간 장면으로 넣을지 사전 녹화 화면으로 넣을지
- 정확한 시간표는 최종 기능과 실제 주행 시간이 확정된 뒤 다시 작성한다.
