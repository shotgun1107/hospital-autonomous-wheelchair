## 대회 MVP

### MVP MUST 후보 — 팀 합의 전

- 인형을 태운 한 대의 축소 차량
- 스스로 승하차할 수 있는 비응급 환자를 전제로 한 두 요청 흐름
- 저속 구동과 물리 E-stop
- 대기 위치→승차 지점→목적지 종단 주행
- 선택한 장애물 대응 방식을 보여줄 수 있는 통제된 시연 경로
- 목적지 도착 목표시각을 입력하는 의료진 예약
- 환자 탑승 확인 전까지의 의료진 예약 목적지·도착 목표시각 수정
- 환자 탑승 확인 전까지의 의료진 예약 취소와 빈 차량 재배정·복귀
- 승차장 태블릿·키오스크의 환자 직접 호출
- 미시작 요청 충돌 시 의료진 예약 기본 우선과 의료진의 순서 변경
- 사용 중 요청의 대기열 등록, 대기 순번과 예상 대기시간 표시
- QR 탑승 확인 전까지의 환자 요청 취소
- 단일 활성 미션과 동일 미션 ID
- 고정 모형 QR을 이용한 탑승·미션 확인
- QR 불일치 시 목적지 운행 금지와 담당 의료진 웹 알림
- 예약 환자 부재의 의료진 보고 후 자동 복귀
- 직접 호출 환자 부재 시 기본 3분 대기·소리 알림·자동 복귀(시연 10초)
- 목적지 도착 지연 예상의 의료진 알림과 운행 계속
- 장애물 감지 후 로컬 정지
- 움직이는 사람을 포함한 장애물 상황의 공통 대응
- 장애물 발생 시 안전정지 후 전체 대체 경로 선택 또는 제한적 현재 경로 수정
- 대체 이동 방법이 없거나 안전성을 판단할 수 없으면 `BLOCKED`로 정지
- 목적지 운행 후 대기 위치 자동 복귀
- 센서 자동 하차 확인과 환자 버튼·의료진 확인 fallback
- 승객의 `정지·도움 요청`, 즉시 정지, 현장 알림음·화면 표시와 의료진 웹 알림
- 환자 화면의 배정·예상 도착시간·운행 상태·취소·도움 요청과 병원 지도의 예정 경로·의미적 위치
- 의료진 충돌 요청 목록의 환자 ID·목적지 표시
- 탑승 전 취소된 빈 휠체어의 다음 요청 재배정 또는 자동 복귀
- 출발 전 배터리 확인과 운행 중 일반 저전력의 현재 운행 완료 후 복귀
- 즉시 운행을 계속할 수 없는 임계 전원 문제의 안전정지
- 경로·통신 상실 정지와 수동 회수
- 미션·목적지·의미적 위치·진행 상태·정지 이유 표시
- 이벤트·시험 로그
- 보고서, 공개 GitHub와 3분 영상의 병행 준비

### MVP SHOULD 후보 — 팀 합의 전

- 두 장애물 대응 방식을 모두 보여주는 확장 시연
- 초음파 거리·장애물 상태 표시. 센서 모델·개수·배치·무응답 처리 합의 뒤 범위를 정한다.
- PWA 설치와 구간 진행률

### CUT

- 미지 환경의 범용 자율주행
- 움직이는 사람 사이를 예측 통과하는 동적 회피
- 사전에 허용되지 않은 공간의 임의 탐색
- 실제 환자·성인 탑승
- 실제 EMR·HIS 연동
- 복수 휠체어 배차
- 정밀 좌표 관제
- 별도 네이티브 앱 두 개
- 클라우드 필수 의존
- 실제 생체신호 측정·위급 판단과 건강관리 모듈 연동
- 환자별 접근성 프로필과 청소·충전·정비의 전체 운영 상태 관리

## 내부 완성도 기준

다음 수치는 공식 대회 요구가 아니라 내부 품질 목표다.

- 같은 조건의 정상 종단 운행 5회 연속 성공
- 장애물 정지 시험 5회 모두 무접촉
- 기존 이동 경로가 막혔을 때 대체 경로 선택 반복 성공
- 대체 이동 방법이 없을 때 움직이지 않고 `BLOCKED`로 종료
- E-stop 후 자동 재출발 없음
- 통신 끊김 시 안전정지
- 경로 상실 또는 진행 상태 불일치 시 안전정지
- 서버·로봇·영상에서 동일 미션 ID 확인
- QR 확인 전 목적지 운행이 시작되지 않음
- QR 불일치 한 번에도 목적지 운행을 시작하지 않고 담당 의료진 웹 알림 표시
- 목적지 운행 종료 후 빈 휠체어가 대기 위치로 복귀
- 탑승 확인 전 환자 직접 호출·의료진 예약 취소 후 다음 요청 재배정 또는 대기 위치 복귀
- 의료진 예약 환자 부재를 의료진에게 보고한 뒤 요청 종료·자동 복귀
- 직접 호출 환자 부재 시 10초 대기·소리 알림 후 자동 복귀
- 센서 판단이 불확실할 때 하차 완료 버튼 또는 의료진 확인 전 자동 복귀하지 않음
- 도움 요청 시 즉시 정지하고 의료진 확인 전 자동 재출발하지 않음
- 출발 조건 미달 배터리에서 새 미션을 시작하지 않음
- 승객 운행 중 일반 저전력에서는 현재 운행 완료 후 복귀
- 임계 전원 문제에서는 운행을 계속하지 않고 안전정지
- 각 시험에 속도, 바닥·조명, 배터리, 장애물 조건, 시간과 결과 기록
