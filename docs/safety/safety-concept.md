# 대회용 축소 모형 안전 원칙 초안

## 적용 범위

이 문서는 인형이 탑승하는 저속 축소 모형의 상위 안전 원칙만 다룬다. 실제 환자용 제품의 기계·의료 안전성을 검증하지 않는다.

## 현재 합의된 원칙

- 실제 사람을 태우지 않는다.
- 웹이나 서버가 멈춰도 물리 비상정지와 로컬 정지가 가능해야 한다.
- 장애물을 발견하면 경로 변경보다 먼저 정지한다.
- 안전한 대체 이동 방법을 확인하지 못하면 움직이지 않는다.
- 하차 완료가 확인되기 전에는 빈 차량 자동 복귀를 시작하지 않는다.
- 승객의 `정지·도움 요청`이 들어오면 즉시 정지하고 의료진이 확인하기 전에는 자동 재출발하지 않는다.
- QR이 현재 미션과 일치하지 않으면 목적지 운행을 시작하지 않고 담당 의료진에게 알린다.
- 새 미션 출발 전 배터리 상태를 확인하고, 임계 전원 문제에서는 운행 계속보다 안전정지를 우선한다.
- 승객 운행 중 일반 저전력이 확인되면 현재 목적지와 하차까지 마친 뒤 대기 위치로 복귀하고 새 미션을 받지 않는다.
- 비상정지, 경로 상실 또는 통신 이상 뒤에는 임의로 자동 재출발하지 않는다.
- 복구할 수 없으면 모터를 멈추고 사람이 모형을 회수한다.

## 큰 구성에서 먼저 정할 사항

- 물리 비상정지와 로컬 보호정지의 책임을 어디에 둘 것인가?
- 장애물로 인한 정상 경로 변경과 위험으로 인한 보호정지를 어떻게 구분할 것인가?
- 어떤 상황에 현장 확인이 필요하고 어떤 상황에 자동으로 같은 이동을 계속할 수 있는가?
- 사용자 화면에는 어떤 정지·실패 이유를 보여줄 것인가?

## 기술 설계로 미룬 사항

- 구동 차단 회로와 전기적 구성
- 장애물·경로·통신·배터리 판정 방법과 임계값
- 감지거리, 정지거리, 속도와 안전 여유 계산
- 센서 조합, 데이터 유효성 판단과 반복 시험 횟수
- 내부 안전 상태와 오류 코드

구체적인 합격 기준은 하드웨어와 최대 시연 속도가 확정된 뒤 반복 시험으로 정한다.
