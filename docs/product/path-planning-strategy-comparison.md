## 이 문서가 확정하지 않는 것

이 문서는 다음 내용을 선택하거나 추천하지 않는다.

- 두 경로 기능과 조합 운용 정책 중 최종 적용 범위 또는 대회 MVP 범위
- 지도 표현, 좌표계와 위치 추정 방식
- 센서 종류, 조합과 수치 성능
- 경로 계산 알고리즘과 경로 추종 방식
- 경로 판단의 실행 위치와 통신 방식
- 실제 재출발 권한과 안전·권한 흐름
- 인터페이스, 메시지 형식, 의사코드와 구현

이 승인은 두 경로 기능과 조합 운용 정책의 기능 범위·요구 정보 비교에만 적용된다. 특정 기능·정책이나 구현 기술의 채택을 의미하지 않는다.

## 상속하는 승인 기준선

두 경로 기능과 조합 운용 정책 모두 다음 원칙을 바꾸지 않는다.

- 알려진 지도를 전제로 한다.
- 등록된 지점 사이를 이동한다.
- 단층의 통제된 공간과 한 대의 휠체어를 전제로 한다.
- 예정 경로를 방해해 충돌 가능성이 생기면 다른 주행 행동보다 안전정지 동작을 먼저 시작한다.
- 정지 뒤 안전한 대체 이동이 가능한지 판단한다.
- 대체 이동이 가능하면 같은 미션과 목적지를 유지한다.
- 대체 이동이 없거나 판단이 불충분하면 정지 상태를 유지한다.
- 경로가 계산됐다는 사실만으로 실제 이동을 재개하지 않는다.

마지막 항목은 구체적인 재출발 절차를 설계한다는 뜻이 아니다. 2·3단계에서 승인된 `경로 관점의 가능 판정과 실제 이동 허가는 다르다`는 경계만 상속한다.

## 이번 비교 대상의 범위

본 단계의 세 비교 대상은 경로 기능 전체를 대체하는 세 가지 완결 전략이 아니다. 안전정지 뒤 원래 경로를 그대로 재개할 수 없는 상황에서 검토할 두 대체 이동 기능과 그 조합 운용 정책을 비교한다.

전체 경로 기능에는 이 비교 대상 외에도 다음 공통 결과가 존재한다.

- 원래 경로 그대로 계속
- 안전정지
- 기다린 뒤 재평가 `[후속 미정]`
- 정지 뒤 원래 경로 재개 가능 판정
- 정지 유지
- 사람 지원 필요

따라서 일시적 장애물에 대한 정지·재판단·원래 경로 재개와 자동 해결 불가 시 사람 지원은 두 대체 이동 기능과 별도 결과다. 이 경계 때문에 D-01/D-06과 R-01은 대체 이동 기능 선택이 아니라 원래 경로 재개 판단에 연결되고, S-03/C-02는 어느 대체 이동 기능도 실행하지 않는 상황으로 남는다.

## 비교 대상의 기술 중립적 정의

### 1. 전체 경로 재선택

현재의 유효한 위치와 진행 상태를 새 출발 조건으로 삼아, 동일한 목적지까지 이어지는 상위 경로 구간의 순서를 다시 선택하는 기능이다.

- 핵심 변화: 현재 위치 이후의 상위 경로 노드·통로·구간 순서가 바뀐다.
- 유지되는 것: 현재 미션과 목적지
- 필수 경계: 대체 통로의 존재뿐 아니라 현재 위치·방향에서 해당 통로의 첫 구간까지 실제 연결 가능한 경로가 있어야 한다.
- 기능 밖의 문제: 선택된 경로를 실제로 추종하는 방식과 통로 안의 순간적인 충돌 회피

로봇이 이미 막힌 복도 안에 들어갔다면 다른 복도가 지도에 존재한다는 사실만으로 충분하지 않다. 현재 위치에서 필요한 후퇴·방향 전환이 가능한지, 대체 통로 진입점까지 도달할 수 있는지와 새 경로의 첫 구간이 실제로 이어지는지를 판단할 수 있어야 한다. 후퇴·회전 방법 자체는 이 단계에서 설계하지 않는다.

### 2. 현재 경로의 제한적 수정

상위 경로 구간의 순서를 변경하지 않고, 허용된 국소 범위 안에서 일시적으로 기존 경로를 벗어났다가 승인된 위치와 방향으로 다시 합류하는 기능이다.

- 핵심 변화: 같은 통로·같은 상위 구간을 유지하면서 현재 경로의 일부만 바꾼다.
- 유지되는 것: 현재 미션, 목적지와 원래 경로의 나머지 부분
- 필수 경계: 다른 통로로 진입하거나 상위 구간 순서가 바뀌면 제한적 수정만의 결과가 아니다.
- 기능 밖의 문제: 다른 통로로 갈아타야 하는 연결 단절과 허용 범위 밖의 탐색

### 3. 두 경로 기능의 조합 운용 정책

전체 경로 재선택과 제한적 현재 경로 수정 기능을 모두 보유하고, 언제 어느 기능을 검토·선택·전환·중단할지를 다루는 상위 운용 정책이다.

- 핵심 변화: 경로를 직접 생성하는 세 번째 방식이 아니라 두 경로 생성 기능을 조정한다.
- 유지되는 것: 현재 미션과 목적지
- 추가 문제: 어느 판단을 적용할지, 계산 중 상황이 바뀌었을 때 어느 결과가 유효한지와 전환 실패를 어떻게 검출할지

조합 방식은 앞선 두 방식과 동일 수준의 단일 경로 생성 방식이 아니라, 두 기능의 선택·우선순위·전환·중단을 정의하는 상위 운용 구조다.

기능 경계는 다음처럼 구분한다.

- 상위 경로 노드·통로·구간 순서가 바뀜: 전체 경로 재선택
- 같은 상위 통로·구간 안에서 제한적으로 이탈한 뒤 복귀: 제한적 현재 경로 수정
- 제한적 수정 중 다른 통로로 들어감: 전체 경로 재선택 또는 조합 운용에 해당
- 전체 재선택을 위해 현재 통로 안의 후퇴·회전·재합류가 함께 필요함: 두 기능의 조합이 필요한 사례일 수 있음

이 단계에서는 조합 운용 정책의 실제 선택·우선순위·전환·중단 규칙을 설계하지 않는다. 비교해야 할 항목과 추가 부담의 존재만 기록한다.

## 여섯 기준 종합 비교

| 비교 기준 | 전체 경로 재선택 | 제한적 현재 경로 수정 | 두 경로 기능의 조합 운용 정책 |
|---|---|---|---|
| 지도 의존성 | 다른 통로와 갈림길을 포함한 전체 연결 관계, 통행 불가 구간, 대체 경로의 상태와 현재 위치에서 진입점까지의 연결 가능성이 필요하다. 실제 대체 통로가 없는 지도에서는 기능 차이를 만들 수 없다. | 현재 경로 주변의 허용·금지 경계, 실제 통과 공간, 이탈·재합류 가능 구역과 방향이 필요하다. 전체 갈림길 정보는 필수가 아닐 수 있다. | 두 지도 정보가 모두 필요하며, 전체 통로 상태와 local 허용 공간이 서로 모순되지 않아야 한다. |
| 위치정보 요구량 | 현재 어느 경로 구간에 있고 어느 방향으로 진행하는지, 현재 상태를 새 출발 조건으로 삼아 다른 경로의 첫 구간까지 연결할 수 있는지를 판단할 수준이 필요하다. 의미적 구간 수준으로 충분한지는 지도 표현에 따라 달라진다. | 차체가 현재 경로와 장애물에 대해 어디에 있는지, 허용 범위 안에서 이탈·재합류할 수 있는지를 판단할 수준이 필요하다. 일반적으로 전체 재선택보다 더 세밀한 공간 정보에 민감하다. | 두 수준을 모두 만족하고 같은 시점·상황을 나타내는지 확인해야 한다. 한쪽만 신뢰 가능하면 다른 기능까지 자동으로 허용할 수 없다. |
| 센서·상위 영역 정보 요구량 | 적어도 현재 통로가 막혔는지와 후보 통로를 사용할 수 있는지를 판단할 정보가 필요하다. 정확한 장애물 윤곽이 경로 선택 자체에 항상 필요한 것은 아니며 통행 상태 정보의 출처도 미정이다. | 장애물이 차지한 범위와 주변 통과 여유는 직접 필요하다. 대상 상태 변화는 동적 대응을 범위에 포함할 때만 조건부로 필요하며 정보 획득 장치는 미정이다. | 통로 폐쇄 판단과 local 통과 가능 판단을 모두 제공해야 하며, 서로 다른 출처·시점의 정보를 섞지 않아야 한다. |
| 실패 시 안전정지 가능성 | 다른 허용 경로가 없거나 후보 경로의 상태가 불확실하면 경로 없음 또는 판단 불충분으로 닫고 정지 유지가 가능하다. 오래된 통행 정보로 막힌 경로를 다시 고르는 위험이 있다. | 통과 여유, 차체 수행 가능성 또는 재합류를 충분히 판단하지 못하면 수정을 만들지 않고 정지 유지가 가능하다. 무리한 좁은 공간 통과와 허용 범위 이탈 위험이 있다. | 두 하위 판단 모두 정지로 닫을 수 있어야 한다. 추가로 잘못된 방식 선택, 전환 중 결과 불일치와 반복 전환이 실패 원인이 된다. |
| 시연 설명력 | 현재 통로 차단 뒤 다른 복도로 이동하는 장면이 명확하다. 단, 실제 갈림길과 대체 통로가 있어야 차이가 보인다. | 장애물 앞 정지 뒤 주변을 돌아 원래 선으로 복귀하는 움직임을 직접 보여줄 수 있다. 단, 충분한 공간과 차체 동작이 있어야 한다. | 서로 다른 장애물 상황에서 두 대응을 보여줄 수 있어 기능 범위는 넓게 보인다. 반면 짧은 시연에서 전환 이유와 안전 실패 처리를 함께 설명하기 어렵다. |
| 일정·예산 부담 | 대체 통로가 있는 지도 준비, 통행 상태 반영과 현재 상태에서 새 경로가 이어지는지 검증해야 한다. local 공간 수정까지 포함하지 않으면 상대적인 기능·시험 범위는 한정된다. | 차체 크기·회전, 통로 폭, 장애물 공간 정보와 반복적인 움직임 검증이 필요하다. 필요한 관측·조정·실물 시험 부담이 커질 수 있다. | 각 기능의 단독 시험 외에도 선택·전환·취소·재시도·결과 최신성·반복 전환 시험이 추가되므로, 검증 범위가 단순 합보다 커질 수 있으며 일반적으로 더 복잡하다. |

표의 `센서·상위 영역 정보 요구량`은 특정 센서를 선택한다는 뜻이 아니다. 센서, 지도 관리 또는 운영 서버 중 어디에서 오는지 정하지 않고 경로 기능이 받아야 하는 장애물·통행 상태 정보의 범위와 세밀함만 비교한다.

## 조합 운용 정책을 공정하게 비교하기 위한 규칙

조합 운용 정책을 두 경로 기능의 단순 합집합이나, 결과를 본 뒤 더 잘된 쪽만 고르는 방식으로 비교하면 기능 범위는 과대평가되고 부담은 과소평가된다. 이 문서에서는 다음 원칙으로 비교한다.

- A-05/D-02/C-01처럼 두 경로 기능이 모두 조건부 대응할 수 있는 시나리오를 조합 운용 정책의 기능 두 개로 중복 계산하지 않는다.
- A-03/A-04/A-08/S-03/S-05/C-02/C-04/C-05의 보수적 정지는 두 경로 기능과 조합 운용 정책의 공통 합격 조건이며 조합 운용만의 추가 기능으로 계산하지 않는다.
- D-06/R-01은 대체 이동 기능의 수가 아니라 변화·해소 뒤 재판단과 반복 전환 위험을 확인하는 순차 상황으로 본다.
- 지도, 차체와 공통 안전정지처럼 두 경로 기능이 공유하는 의존성은 한 번만 계산한다.
- 전체 재선택 전용, 제한적 수정 전용과 조합 전환 때문에 추가되는 의존성을 분리한다.
- 같은 실제 공간 상태, 시작 위치, 목적지와 장애물 변화 순서를 사용하되 한 비교 대상만 추가로 요구하는 정보는 해당 기능·정책의 의존성 부담으로 기록한다.
- `필요 정보가 없어 평가 불가`, `기능·정책을 실행했지만 실패`, `계속하지 않고 안전하게 정지`를 서로 다른 결과로 기록한다.
- 논리 시험, 시각 시뮬레이션과 실물 시험의 증거를 하나의 성공 점수로 합치지 않는다. `[VAL-06]`

조합 운용 정책의 추가 부담은 다음처럼 분리한다.

| 의존성 분류 | 내용 | 관련 ID |
|---|---|---|
| 두 기능·조합 정책 공통 | 지도 허용·통과 공간, 미션·목적지, 현재 진행 판단, 충돌 가능성, 차체 수행 가능성, 정지 우선, 실행·통신 조건과 결과 최신성 | MAP-01/02/04/06/07, LOC-01~05, OBS-01/04/06, VEH-01~05, SAFE-01~07, SYS-01~07, VAL-01/04/05/06 |
| 전체 재선택 추가 | 다른 통로 연결 관계, 통행 불가 구간, 복수 경로 판단 기준 | MAP-03/05/09 |
| 제한적 수정 추가 | 장애물 공간 범위, 허용 이탈 공간과 재합류 가능성 | MAP-08, OBS-02; 변화 사용 시 OBS-03 |
| 조합 전환 검증 범위 확대 | 두 결과와 현재 상태가 일치하는지, 전환 위치에서 실제 수행 가능한지, 반복 전환·늦은 결과를 구분할 수 있는지 | 새 정보 의존성을 추가하지 않고 공통 MAP-04/06, LOC-02/03/05, SYS-04~07, VAL-02/04/05의 검증 경우가 늘어남 |

조합 전환의 구체 순서·조건·종료 기준은 아직 미정이며 이 단계에서 설계하지 않는다. 비교에서는 단독 기능 시험 외에 양방향 전환, 전환 중 결과 무효화, 반복 전환, 한쪽 판단 정보만 불충분한 상황이 추가된다는 사실만 일정·검증 부담으로 반영한다.

조합 운용 정책에서 비교해야 하지만 4단계에서 실제 규칙을 결정하지 않는 항목은 다음과 같다.

| 추가 비교 항목 | 비교할 내용 |
|---|---|
| 최초 선택 | 어떤 상황에서 전체 재선택 또는 제한적 수정을 검토할 수 있는가 |
| 우선순위 | 두 경로 기능이 모두 가능할 때 어떤 판단 기준이 추가로 필요한가 |
| 전환 | 한 기능을 적용할 수 없거나 적용 중 실패했을 때 다른 기능 검토로 넘어갈 수 있는가 |
| 취소 | 새 장애물이나 상태 변화가 생겼을 때 기존 결과를 무효화해야 하는가 |
| 결과 최신성 | 계산 결과가 현재 지도·위치·장애물·미션 상태와 일치하는가 |
| 반복 방지 | 두 기능을 계속 번갈아 검토하는 상황을 어떻게 검출할 것인가 |
| 보수적 종료 | 선택·전환 판단이 불충분할 때 어느 기능도 실행하지 않고 정지 유지로 닫히는가 |

이 표는 비교해야 할 문제의 목록이며 선택값, 우선순위, 전환·취소·반복 종료 규칙을 확정한 것이 아니다.

## 기준별 상세 비교

### 지도 의존성

#### 전체 경로 재선택

- 현재 활성 경로와 등록 지점·구간 순서가 필요하다. `[MAP-01]`
- 다른 통로를 포함한 연결 관계가 있어야 한다. `[MAP-03]`
- 현재 막힌 구간과 후보 통로의 실제 사용 가능 상태를 반영해야 한다. `[MAP-05]`
- 여러 후보가 있을 때 허용 후보를 구분할 상위 기준이 필요하다. `[MAP-09]`
- 현재 위치·진행 방향을 새 출발 상태로 두고 대체 통로의 첫 구간까지 실제로 이어지는지 확인해야 한다. `[MAP-02/04, LOC-02]`
- 필요한 경우 현재 통로 안에서 후퇴하거나 방향을 바꿔 진입점까지 갈 수 있는지도 차체 수행 가능성에 포함해 판단해야 한다. `[MAP-04, VEH-01/02]`

#### 제한적 현재 경로 수정

- 현재 경로 주변의 이동 허용·금지 경계가 필요하다. `[MAP-02]`
- 통로·출입구·모퉁이의 실제 통과 공간이 필요하다. `[MAP-04]`
- 원 경로에서 이탈할 수 있는 공간과 안전한 재합류 구역·방향이 필요하다. `[MAP-08]`
- 다른 통로 전체의 연결 관계는 필수가 아닐 수 있지만, 수정 범위를 넘어서거나 다른 상위 통로로 들어가면 이 기능만의 결과가 아니다.

#### 두 경로 기능의 조합 운용 정책

- 위 두 묶음이 모두 필요하다.
- 동일한 실제 공간을 전체 연결 관계와 local 허용 공간이 다르게 표현하면 전환 결과를 신뢰할 수 없다. `[MAP-05/06, SYS-07]`
- 이 단계에서는 지도 구조나 일치 확인 형식을 정하지 않는다.

### 위치정보 요구량

#### 전체 경로 재선택

- 현재 미션·목적지와 운행 단계를 알아야 한다. `[LOC-01]`
- 현재 경로 구간과 진행 방향을 다른 경로의 시작 상태에 연결할 수 있어야 한다. `[LOC-02]`
- 현재 위치·진행 판단이 신뢰 가능한지 알아야 한다. `[LOC-03/05]`
- 구간 수준으로 충분한지 연속 위치가 필요한지는 지도 표현과 실제 차체 이동에 따라 달라지므로 미정이다.

#### 제한적 현재 경로 수정

- 현재 위치와 원 경로의 상대 관계를 판단해야 한다. `[LOC-02]`
- 장애물 주변의 허용 공간, 차체 외곽과 재합류 가능성을 함께 판단할 수준이 필요하다. `[LOC-03/05, MAP-08, VEH-01/02]`
- 위치 오차가 허용 이탈 범위나 통로 여유보다 크면 안전한 수정 여부를 판단할 수 없다.

#### 두 경로 기능의 조합 운용 정책

- 전역적 경로 진행 상태와 local 공간 상태를 모두 알아야 한다.
- 두 판단이 서로 다른 시점의 위치를 사용하면 잘못된 전환이 생길 수 있다. `[SYS-07]`
- 필요한 좌표계와 정합 방식은 이 단계에서 정하지 않는다.

`직접 필요`는 특정 카메라, 거리 센서 또는 다른 장치를 채택한다는 뜻이 아니다. 해당 기능·정책의 가능 여부를 판단하려면 그 의미 정보가 필요하다는 뜻이다.

### 실패 시 안전정지 가능성

먼저 정지한다는 기준선은 두 경로 기능과 조합 운용 정책의 성능 차이가 아니라 공통 합격 조건이다.

| 실패 상황 | 전체 재선택 | 제한적 수정 | 조합 운용 정책 |
|---|---|---|---|
| 대체 경로·수정 경로가 없음 | 경로 없음으로 정지 유지 | 수정 불가로 정지 유지 | 두 방식 모두 불가로 정지 유지 |
| 위치 판단 불충분 | 새 경로를 실행하지 않음 | 수정 경로를 만들거나 실행하지 않음 | 어느 방식으로도 전환하지 않음 |
| 장애물 정보 불충분 | 후보 통로의 안전성을 가정하지 않음 | 빈 공간을 가정해 통과하지 않음 | 불확실한 하위 결과를 선택하지 않음 |
| 계산 중 상황 변화 | 현재 상황에서 여전히 유효한지 판단할 수 없으면 사용하지 않음 | 현재 장애물·재합류 상태와 맞지 않으면 사용하지 않음 | 오래된 결과와 하위 방식 사이에서 임의 전환하지 않음 |
| 대체 이동 중 새 장애물 | 다시 안전정지 동작을 우선 개시 | 다시 안전정지 동작을 우선 개시 | 현재 사용 중인 방식과 관계없이 다시 안전정지 동작을 우선 개시 |
| 실제 정지 완료 불확실 | 새 경로가 있어도 이동 재개를 승인하지 않음 | 수정 경로가 있어도 이동 재개를 승인하지 않음 | 어느 결과도 이동 재개의 근거로 사용하지 않음 |

이 표는 5단계의 안전·권한 흐름을 설계한 것이 아니다. 승인된 정지 우선·판단 불충분 시 정지 유지 원칙이 각 기능·정책 실패에도 적용되는지만 비교한다.

## 두 경로 기능과 조합 운용 정책이 공통으로 해결하지 못하는 것

어느 경로 기능·조합 운용 정책을 선택해도 다음 문제가 자동으로 해결되지는 않는다.

- 안전한 경로가 실제로 하나도 없는 상황
- 현재 위치·장애물·지도 판단이 불충분한 상황
- 물리 정지 성능과 관측 여유가 충돌 전 정지를 허용하지 않는 상황
- 좁은 통로에서 사람·외부 이동체와 장기간 서로 양보하지 못하는 상황
- 계산된 경로를 차체가 실제로 추종할 수 없는 상황
- 통신 단절, 임계 전원, 비상정지와 실제 재출발 권한
- 실제 환자 탑승 환경의 안전성·인증

따라서 경로 기능·조합 운용 정책의 목적지 도달 성공만으로 제품 안전 성공을 주장할 수 없다.

## 4단계 비교 결과

이 단계에서 도출되는 중립적 결과는 다음과 같다.

1. 전체 경로 재선택과 제한적 현재 경로 수정은 같은 기능의 단순한 크기 차이가 아니다.
2. 전체 재선택은 다른 통로의 연결·상태 정보에 직접 의존한다.
3. 제한적 수정은 현재 경로 주변의 공간, 차체 수행 가능성과 재합류 판단에 직접 의존한다.
4. 조합 운용 정책은 두 기능 범위를 조정하지만 두 의존성 묶음과 선택·전환 검증 부담도 함께 가진다.
5. 정적 장애물은 항상 전체 재선택, 동적 장애물은 항상 제한적 수정처럼 물체 상태만으로 대체 이동 기능을 고정할 수 없다.
6. 두 경로 기능과 조합 운용 정책 모두 정보가 없거나 불충분할 때 정지 유지로 종료할 수 있어야 한다.
7. 현재 미확정 정보만으로는 어느 기능·정책도 최종 채택할 수 없다.

이 결과는 6단계의 조건부 추천안이 아니다. 두 경로 기능과 조합 운용 정책의 차이와 필요한 정보만 비교한 것이다.
