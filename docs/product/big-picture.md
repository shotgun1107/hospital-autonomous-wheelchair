# 프로젝트 큰 틀 기준선

- 상태: 개인 기획 기준선 · 팀 합의 전
- 목적: 세부 기술이나 운영 예외를 정하기 전에 프로젝트가 무엇인지 고정한다.

현재 기획 단계에서는 이 문서를 우선 기준으로 사용한다. 다른 제품·운영·시연 문서의 세부 항목은 팀 합의 전 브레인스토밍 초안이며 구현 지시가 아니다.

## 한 문장 정의

병원 관계자의 예약 이동과 환자의 직접 호출을 한 대의 자율주행 휠체어 운행으로 연결해, 거동이 불편하지만 스스로 승하차할 수 있는 비응급 환자의 원내 이동을 돕는 종단 시스템이다.

## 해결하려는 문제

- 검사실·진료실·병실 이동 때 반복되는 의료진의 환자 이송 부담
- 환자가 필요할 때 이동수단을 직접 요청하기 어려운 문제

두 문제 중 하나만 선택하지 않고 의료진 업무 감소와 환자 이동 자율성을 함께 다룬다.

## 핵심 사용자 흐름

### 의료진 예약

의료진이 환자 식별정보, 승차 지점, 목적지와 필요한 시간을 등록하면 시스템이 적절한 시점에 빈 휠체어를 승차 지점으로 보낸다.

### 환자 직접 호출

환자가 등록된 승차 지점에서 목적지를 선택해 호출하면 빈 휠체어가 해당 승차 지점으로 이동한다.

두 흐름은 동일한 휠체어 미션 체계로 연결한다. 구체적인 우선순위, 취소, 노쇼와 환자 확인 방식은 큰 틀 확정 뒤 다룬다.

## 대회 프로토타입

- 영유아보다 조금 작은 인형이 타는 축소형 휠체어 한 대
- 실제로 움직이는 자율주행 하드웨어 포함
- 사전에 병원 지도가 주어졌다고 가정한 통제된 평면 시연 공간
- 등록된 대기 위치, 승차 지점과 목적지 사용
- 호출 또는 예약부터 빈 차량 이동, 승객 이동, 운행 종료와 자동 복귀까지 종단 시연
- 실제 사람은 탑승시키지 않음

## 자율 이동의 상위 목표

- 주어진 지도에 따라 승차 지점과 목적지 사이를 자율 이동한다.
- 장애물을 발견하면 충돌 전에 정지한다.
- 가능한 경우 다른 경로를 선택하거나 현재 경로를 제한적으로 수정해 같은 목적지로 계속 이동한다.
- 안전한 이동 방법을 판단할 수 없으면 정지하고 사람의 개입을 요청한다.

전체 경로 재선택, 제한적 경로 수정 또는 둘 다를 구현할지는 팀과 합의한다. 지도 표현, 위치 추정, 센서, 경로 알고리즘과 제어 방식은 이후 기술 설계에서 정한다.

## 큰 시스템 영역

1. 환자·의료진 사용자 화면
2. 요청·예약·대기·미션 상태를 관리하는 서버
3. 지도 기반 이동과 장애물 대응을 담당하는 자율주행 소프트웨어
4. 센서·모터와 저수준 안전을 담당하는 펌웨어·하드웨어
5. 운행 상태를 확인하는 관제 화면과 시험·시연 자료

각 영역의 세부 API, 보드 배치, 통신 방식과 내부 모듈은 아직 확정하지 않는다.

## 현재 범위의 안전 경계

- 실제 환자용 의료기기나 성인 탑승 안전성을 검증했다고 주장하지 않는다.
- 비응급 상황과 스스로 승하차할 수 있는 환자를 서비스 전제로 둔다.
- 실제 EMR·HIS와 개인정보를 연동하지 않고 가상 환자 데이터를 사용한다.
- 한 대의 휠체어와 통제된 단층 시연 공간에 집중한다.
- 물리 비상정지와 장애물 앞 정지를 포함한다.

## 차별화 방향

자율주행 휠체어 자체의 최초성을 주장하지 않는다. 의료진 예약과 환자 직접 호출을 실제 빈 차량 이동, 승객 이동, 장애물 대응과 자동 복귀까지 하나의 종단 흐름으로 연결하는 점을 작품의 중심으로 둔다.

## 팀 역할 상태

- 하드웨어·펌웨어·임베디드 팀 2명과 소프트웨어 팀 2명으로 역할 분배를 완료했다.
- 사용자는 Software A로서 경로 알고리즘과 자율주행 소프트웨어 영역을 담당한다.
- 소프트웨어 팀은 서버, 프론트엔드, ROS 2, 자율주행 알고리즘, AI, 시뮬레이터와 하드웨어 통신 게이트웨이·프로토콜을 담당한다.

## 팀과 먼저 합의할 항목

- 축소형 차체 크기, 확보 가능한 하드웨어와 전체 예산
- 시연 공간의 크기, 승차 지점·목적지 수와 갈림길 구성
- 전체 경로 재선택, 제한적 현재 경로 수정 또는 두 기능 모두 중 대회 구현 범위
- 3분 영상에서 보여줄 핵심 종단 장면
- 내부 일정과 기능 동결 기준

## 지금 확정하지 않을 항목

- 예약 우선순위 계산, 노쇼 시간, 취소·수정의 모든 예외 처리
- QR, 환자별 접근성, 도움 요청과 청소·정비 화면의 세부 동작
- 지도·경로 데이터 구조, 위치 추정, 센서와 알고리즘
- 보드 구성, 통신 프로토콜, 내부 상태명과 안전 임계값
- 실제 병원 시스템 연동과 의료기기 수준의 판단
