# 경로 기능 1단계 기준선

- 상태: 사용자 승인
- 승인일: 2026-08-09
- 목적: 경로 기능의 상세 상황과 기술을 논의하기 전에 전제와 공통 장애물 대응 원칙을 고정한다.

## 확정 사항

- 알려진 지도를 전제로 한다.
- 등록된 지점 사이를 이동한다.
- 단층의 통제된 공간을 전제로 한다.
- 한 대의 휠체어를 전제로 한다.
- 예정 경로를 방해해 충돌 가능성이 생긴 장애물이 감지되면 휠체어는 먼저 안전하게 정지한다.
- 정지 후 안전한 대체 이동이 가능한지 판단한다.
- 대체 이동이 가능하면 같은 목적지로 계속 이동한다.
- 대체 이동이 불가능하거나 판단이 불확실하면 정지 상태를 유지한다.

## 미확정 사항

- 정적·동적 장애물별 세부 대응
- SLAM 적용 여부
- 사용할 센서
- 좌표계와 위치 표현 방식
- 구체적인 경로 알고리즘

## 1단계 제외 범위

- 장애물별 상세 상황 정의
- SLAM·센서·좌표계·경로 알고리즘의 선택과 상세 설계
- 시뮬레이션과 제품 코드 구현
