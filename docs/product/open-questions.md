# 미결정 사항

## 제품과 차별화

- 의료진 업무 감소와 환자 이동 자율성이라는 두 가치를 발표에서 어떤 비중으로 설명할 것인가?
- 예상 대기시간을 어떤 기준으로 산정할 것인가?
- 환자 정보에 등록된 담당 의료진·담당 병동 알림 대상이 근무 교대·부재·무응답일 때 어디까지 확대 통보할 것인가?
- 환자 부재와 도움 요청 알림음의 반복 횟수와 간격은 무엇인가?

## 인터페이스와 시연 공간

- 개인 스마트폰 웹과 승차장 태블릿·키오스크를 하나의 반응형 웹으로 만들지 역할별 화면으로 분리할 것인가?
- 환자별 시력·청력·인지 상태와 선호에 따라 어떤 화면·음성 접근성 설정을 제공할 것인가?
- 최종 시연은 대기 위치 1개, 승차 지점 1개와 목적지 몇 개로 구성할 것인가?
- 병원 팔찌·환자 QR과 앱 QR을 실제 미션에 연결할 때 어떤 병원 시스템을 사용할 것인가? 대회 MVP는 고정된 모형 QR을 사용한다.
- 센서 자동 하차 확인이 불확실할 때 환자 버튼과 의료진 확인을 어떤 화면·절차로 제공할 것인가?
- 환자 지도에서 예정 경로와 의미적 위치를 어떤 단위와 주기로 갱신할 것인가?
- QR 불일치 알림 뒤 재확인·미션 종료·현장 확인을 어떤 순서로 처리할 것인가?
- 탑승 확인 전 예약 수정으로 이미 이동 중인 빈 휠체어의 목표가 바뀌면 어떤 안내를 제공할 것인가?
- 실제 서비스에서 청소·충전·정비 상태를 누가 관리하고 상세 사유를 어떤 운영 사용자에게만 보여줄 것인가?
- 충돌 요청 목록에서 항목을 선택했을 때 도착 목표시각 같은 상세정보를 추가로 보여줄 것인가?

## 자율주행과 안전

- 병원 지도가 제공된다는 가정 아래 어떤 장소와 이동 가능 구역까지 표현해야 하는가?
- 전체 대체 경로 선택과 장애물 주변의 제한적 현재 경로 수정 중 무엇을 필수로 할지, 또는 둘 다 포함할 것인가?
- 장애물 상황에서 기다림과 다른 이동 방법 탐색 중 무엇을 선택할지 어떤 상위 조건으로 구분할 것인가?
- 장애물 해소 뒤 경로 관점의 `재개 가능`을 판정할 세부 확인 조건과 승인된 재출발 요청의 생성 주체·방식은 무엇인가? 실제 이동의 로봇 로컬 안전 거부권은 승인됐다.
- 좁은 복도·출입구에서 사람, 병상, 카트 또는 다른 이동체와 대치할 때 우선권과 양보를 어떻게 정할 것인가?
- 불필요한 급정지·반복 정지와 사람이 위험하게 양보한 상황을 어떤 측정 기준과 합격선으로 평가할 것인가?
- 대체 이동 판단을 어디에서 실행하고 승인된 이동·재출발 요청을 로봇, 서버와 현장 운영자 중 누가 생성할 것인가? 최종 실제 이동 허가는 로봇 로컬 안전 게이트가 가진다.
- 관제 화면에는 대체 경로 판단 과정과 실패 이유를 어느 수준까지 보여줄 것인가?
- 경로 상실, 통신 끊김과 배터리 저하가 발생했을 때 사용자에게 어떤 결과와 안내를 제공할 것인가?

## 하드웨어와 배치

- 로봇 로컬 영역 안에서 정지 판단·개시·모터 차단과 최종 이동 안전 게이트를 상위 제어, 저수준 구동과 물리 안전 사이에 어떻게 나눌 것인가?
- 전달된 Arduino 계열 MCU와 초음파 거리 센서의 정확한 모델명은 무엇인가?
- 초음파 센서를 몇 개 사용하며 차체 기준 어느 위치·방향·높이에 장착하는가?
- 각 센서의 실제 측정 주기, 유효 거리, blind zone, timeout과 무응답 표현은 무엇인가?
- 여러 초음파 센서의 상호 간섭을 막기 위해 순차 구동·대기 시간을 어떻게 구성하는가?
- 펌웨어는 원시 거리만 보낼지, 필터된 거리·점유 상태와 오류 상태도 보낼지?
- 초음파 최소안은 장애물 감속·정지만 담당할지, 복수 센서·시간 이력으로 동적 track까지 만들지?
- `no echo`, 범위 밖, 흡음·경사 반사와 장치 오류를 빈 공간과 어떻게 구분할 것인가?
- 하드웨어를 대여할 수 있는가, 직접 구매해야 하는가?
- 팀 전체 예산 상한과 부품 확보 마감은 언제인가?

## 큰 구성 확정 뒤 기술 설계에서 결정

- 목적지 도착 목표시각에서 실제 출발 시점을 산정하는 방식
- 의료진 예약 기본 우선, 목표 도착시각과 장기 대기 방지를 함께 반영하는 세부 스케줄링 방식
- 지도와 경로의 데이터 표현
- 현재 위치와 진행 상태의 추정 방식
- 경로 계산 및 국소 수정 알고리즘
- 제어 보드, 센서, 모터와 통신 방식
- 자동 하차 확인에 사용할 센서와 판정 방식
- 물리 비상정지 회로와 각종 안전 임계값
- 경로 상실, 통신 끊김과 배터리 저하의 구체적인 판정 기준
