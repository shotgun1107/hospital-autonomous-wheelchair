# WHILL 선행 사례 메모

확인일: 2026-08-08

## 공식 자료에서 확인된 범위

WHILL 자율주행 서비스와 병원 공개 사례에는 다음 기능이 설명돼 있다.

- 기체 화면에서 사전 설정된 목적지 선택
- 정해진 병원 경로의 자율 이동
- 하차 후 지정 승차장 또는 스테이션으로 무인 복귀
- 기체 위치·운행 상태 확인과 필요한 장소로의 원격 재배치

공식 자료:

- [WHILL 자율주행 서비스 작동 방식](https://whill.inc/jp/mobility-service/how-it-works/autonomous-drive)
- [요코하마시립시민병원 WHILL 운영 사례](https://yokohama-shiminhosp.jp/introduction/whill.html)

## 확인하지 못한 범위

공개 자료만으로는 다음 사항의 실제 병원 운영 여부를 확정할 수 없다.

- 병원 환자 ID와 실제 EMR·진료 예약의 직접 연동
- 목표 도착시각에서 출발시각을 계산하는 구체적 운영 흐름
- 예약 이동과 현장 직접 호출의 내부 충돌 정책

확인되지 않았다는 사실은 해당 기능이 존재하지 않는다는 증명이 아니다.

## 프로젝트에 주는 의미

다음 기능은 단독 차별점으로 주장하지 않는다.

- 지정 승차장
- 목적지 선택
- 장애물 대응
- 자동 복귀
- 배차·위치·배터리 관제

차별화 후보는 예약 목표시각, 직접 호출, 단일 미션 상태 모델과 실패·수동 회수 추적을 축소형 임베디드 종단 시스템으로 구현하고 반복 검증하는 방식이다. 자율주행 휠체어 자체의 최초성은 주장하지 않는다.
