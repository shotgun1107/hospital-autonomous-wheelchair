# R5-B v2 C++ DWB 공개 10개 이상조건 결과

- 상태: 공개 Ideal 좌·우 10개 기능 통과
- 작업일: 2026-08-16
- 대상: same-direction 공개 5개 × 좌·우 2개
- 컨트롤러: source-derived DWB, C++ 전체 수치 코어와 C++ 동적 안전 배치 사용
- 비범위: Normal·Stress 관측 열화, 50ms 자격, hidden, 실제 사람, 제품 알고리즘 채택

## 1. 시작 결과

기존 C++ DWB를 그대로 공개 10개에 실행했을 때 `4/10`만 도착했다. 열 사례 모두 Actor 추월은
완료했지만, 더 빠른 Actor가 있는 여섯 사례는 우회 구간 끝에서 로봇이 너무 일찍 감속하고
제자리 복귀 회전을 하는 동안 Actor가 다시 따라왔다. 이때 공통 실행 허가는
`R5-B target is no longer conservatively behind the robot`으로 정지시켰다.

따라서 문제는 경로를 못 찾거나 안전 장치가 잘못 막은 것이 아니라, DWB가 짧은 우회 구간의
끝점에 가까워지며 너무 이르게 속도를 줄인 것이었다.

## 2. 최소 보정

두 가지를 DWB의 우회 구간에만 적용했다.

1. 점수 계산에만 우회 종점 앞 `0.30m` 가상 앞보기 점을 추가했다. 실제 실행 경로와 종점은
   바꾸지 않았다.
2. DWB 실행기의 우회 구간 완료 오차만 기존 `0.05m`보다 작은 `0.02m`로 제한했다. 첫 시험의
   `0.01m`는 오른쪽 사례에서 종점 원을 지나치는 문제가 있어 채택하지 않았다.

후보 `217`개, 후보당 `41`개 자세, 2초 예측, 종단 정지, Actor 예측관, 안전거리, 공통 안전
장치, 점수 가중치와 실제 경로는 바꾸지 않았다.

## 5. 결론과 한계

C++ DWB는 공개 이상조건의 같은 방향 Actor 좌·우 10개에서 실제 이탈, 추월, 원 경로 복귀,
도착을 모두 완료했다. 따라서 이 범위에서 DWB가 거의 못 쓰는 상태라는 결론은 해소됐다.

그러나 이것은 잡음과 지연이 없는 Ideal 공개 시뮬레이션의 기능 증거다. Normal·Stress 관측,
50ms 무실패 자격, 다른 동적 상황, hidden, 실물 안전과 제품 채택은 아직 증명하지 않았다.
RPP의 공개 10개 정식 비교도 별도 작업으로 남는다.
