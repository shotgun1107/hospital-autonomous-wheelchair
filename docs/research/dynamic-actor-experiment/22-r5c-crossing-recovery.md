# R5-C 횡단 경로 복구 명세

- 날짜: 2026-08-16
- 범위: 공개 횡단 좌·우, Normal 관측, C++ DWB 경로 기능
- 입력 가정: 카메라 등 상위 관측 영역이 기존 `ActorTrack` 계약을 제공함
- 비범위: 카메라 모델·FOV·가림·사람 검출 구현, 제품 센서 선정, hidden

## 목적

관측이 끊겼을 때 이전 경로 세션과 이동 허가를 계속 사용하지 않는다. 실제 정지를 확인한 뒤
현재 위치, 현재 `stop_epoch`, 새 유효 시작 tick에 묶인 새 횡단 reference와 controller
session을 만들고, 고유 fresh `READY` frame 11개가 다시 모였을 때만 이동을 재개한다.

## 고정 규칙

1. 원본 횡단 경로 형상·좌우 방향·안전거리·Actor 예측관은 변경하지 않는다.
2. 새 세션은 원본 경로 전체를 보존하되 현재 위치가 포함된 local window의 첫 section에서
   실행을 시작한다.
3. 이전 stop epoch, reference session과 resume authorization은 재사용하지 않는다.
4. 추월 완료 판정이 현재 관측에서 더 이상 보수적으로 성립하지 않으면 오류로 계속 가지 않고
   즉시 보호정지한다.
5. 공개 world가 끝나기 전 20 control tick은 새 출발에 쓰지 않고 실제 정지 확인에 사용한다.
6. Stress처럼 충분한 방향 관측을 확보하지 못하면 출발하지 않는다.

## 판정

- 경로 복구 기능: 새 stop-bound session이 두 번 이상 실제 생성되고 이동할 것
- 안전 경계: 최소 Actor·정적 여유 `0.08m` 이상, hard failure 없음
- 종료: 도착하거나 world 종료 전에 실제 정지한 보수적 종료
- 이 시험만으로 실제 카메라 성능, 제품 알고리즘 또는 사람 탑승 안전을 주장하지 않음
