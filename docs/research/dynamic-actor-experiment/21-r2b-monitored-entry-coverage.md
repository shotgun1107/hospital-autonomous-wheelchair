# R2-B 감시 진입 구간과 Actor 출현 보정 명세

- 상태: 공개 시뮬레이션 연구 구현 기준
- 작성일: 2026-08-16
- 대상: 기존 R2-B `ideal_capsule_ground_truth_miss` 2건
- 비범위: 실제 카메라·FOV·가림·검출 성능, 제품 센서 선정, hidden, 제품 알고리즘 채택

## 1. 목적

기존 v6 `second-risk`와 legacy `dynamic-change` 장면은 사람이 지도 내부에 순간 생성된 뒤
관측 지연 동안 직전 `EMPTY` frame만 남는다. 이 조건에서는 예측기가 실제 Actor를 미리
표현할 수 없다.

이번 보정은 과거 `EMPTY`를 안전 증거로 바꾸지 않는다. 원래 장면과 실패 기록을 그대로
보존하고, 별도의 파생 공개 장면에 `감시 접근 구간`을 추가한다. Actor는 위험 관련 구역에
들어오기 전에 같은 식별자·속도·궤적으로 접근 구간에서 관측되며, 진입 시점 이후 궤적은
원래 장면과 정확히 같아야 한다.

## 2. 계약

각 지연 출현 Actor에는 다음 정보를 결박한다.

- 원본 공개 world와 Actor 식별자
- 감시 시작 시각
- 위험 관련 구역 진입 시각
- 감시 시작 위치와 일정한 속도
- 원본 Actor의 진입 위치·속도·반경·revision
- 10Hz 관측과 20-frame 방향 예측이 진입 전에 준비될 수 있는 시간 여유
- 원본 world hash, 파생 관측 world hash와 계약 hash

파생 접근 궤적은 원본 속도로 진입 위치에서 시간을 거꾸로 계산한다.

```text
감시 시작 위치
= 원본 진입 위치 - 원본 속도 × (진입 시각 - 감시 시작 시각)
```

진입 시각의 파생 Actor 상태는 원본 Actor의 최초 상태와 위치·속도·반경·revision까지 정확히
일치해야 한다. 진입 이후에는 원본과 같은 궤적을 사용한다.

## 3. 허가와 금지

### 허가

- 로컬 주행 지도 밖까지 포함할 수 있는 추상 감시 접근 구간
- 공개 Ideal 관측에서 접근 track을 먼저 만들고 기존 방향 예측기를 그대로 실행
- 원본 witness의 경로·시간·차체·안전거리·Capsule 기준을 그대로 재검증
- 원본 실패 장면과 보정 장면을 동시에 회귀 자료로 보존

### 금지

- Actor의 진입 시각·정답 궤적·평가 label을 controller 입력에 전달
- fresh `EMPTY`만으로 출발·재출발 허가
- Actor 반경, 관측 지연, 20-frame 준비 조건, Capsule 또는 안전거리 완화
- 원본 corpus·원본 R2 output·기존 hard failure 삭제 또는 덮어쓰기
- 이 추상 감시 구간을 실제 카메라의 가시영역·가림·검출 성능 증거로 표현

## 4. 공개 보정 대상

1. v6 `second-risk-after-corner`
   - 지연 출현 Actor를 원래 `13.0s` 진입 상태에서 같은 속도로 `0.0s`까지 역산한다.
   - 원래 첫 위험과 두 번째 위험의 실제 궤적·순서는 바꾸지 않는다.
2. legacy `dynamic-change`
   - 두 번째 Actor를 원래 진입 상태에서 `0.0s`까지 역산한다.
   - 첫 Actor와 원래 두 번째 위험의 진입 이후 궤적은 바꾸지 않는다.

원본 world는 음성 회귀로 남기고, 파생 world는 새 hash를 가진 별도 R2-B 연구 입력으로 둔다.

## 5. 검증

### 계약 검증

- 모든 지연 출현 Actor에 접근 계약이 하나씩 존재
- 알 수 없는 Actor, 중복 Actor, 누락 Actor 거부
- 감시 시작은 진입보다 충분히 이르고 episode 범위 안
- 10Hz 20-frame과 Ideal 지연을 포함한 준비 시간이 진입 전에 확보됨
- 진입 경계의 위치·속도·반경·revision 연속성 exact
- 파생 world는 원본 경로·지도·초기 차체·목적지·시간과 일치
- 파생 world와 계약의 hash 불일치 거부

### 결과 검증

- 원본 두 장면은 기존 `ideal_capsule_ground_truth_miss`를 계속 재현
- 파생 두 장면은 Ideal에서 실제 Actor가 있는데 예측 shape가 없는 sample `0`
- 파생 두 장면의 Ideal containment miss `0`
- 원본 witness의 ground-truth 안전 검증 결과를 약화하지 않음
- Normal·Stress가 판단 불충분하면 안전 실패를 지우지 않고 별도 제한으로 남김

## 6. 판정 경계

이 보정이 통과하면 다음만 주장한다.

> 감시 접근 구간에서 Actor track을 미리 제공하는 추상 공개 시뮬레이션 계약에서는 기존
> 내부 순간 생성으로 발생한 Ideal prediction coverage 공백을 제거할 수 있다.

다음은 주장하지 않는다.

- 실제 카메라가 접근 구간 전체를 항상 본다.
- 가림·검출 누락·track 교체가 해결됐다.
- fresh `EMPTY`가 공간 전체의 무출현을 증명한다.
- formal R5-C/R6, hidden 또는 제품 안전 자격이 완료됐다.
