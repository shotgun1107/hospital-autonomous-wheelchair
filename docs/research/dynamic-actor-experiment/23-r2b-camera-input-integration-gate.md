# R2-B 카메라 입력 연결 Gate

## 상태

- 작업일: `2026-08-16`
- 상태: 실제 입력 대기
- 경로 연구 영향: `ActorTrack` 제공 가정의 R1~R7 재검증을 막지 않음
- 제품 센서 채택: 미수행
- 경로 분석 7단계·G1~G5: 미수행

## 현재 확인 결과

집 PC와 현재 저장소를 읽기 전용으로 확인한 결과는 다음과 같다.

- Windows에서 인식된 `Camera`·`Image` 장치: 없음
- 저장소의 카메라 영상: 없음
- 저장소의 사람 검출·추적 모델: 없음
- 저장소의 카메라 드라이버·OpenCV 연결 코드: 없음
- 현재 가상환경의 OpenCV: 미설치
- `ffmpeg`: 확인되지 않음

따라서 실제 카메라 frame, FOV, 가림, 사람 검출과 track 지속성을 시험했다는 주장은 할 수
없다. OpenCV만 설치해도 실제 장치·영상이 없으면 이 Gate는 통과하지 않는다.

이 Gate는 실제 장비 통합용 별도 lane이다. 사용자가 지시한 경로 알고리즘 재검증에서는
카메라 등 상위 영역이 기존 `ActorTrack` 계약을 제공한다고 가정하며, 이 문서의 실제 입력
대기 상태를 R1~R7 경로 연구의 중단조건으로 사용하지 않는다.

## 다음 실행에 필요한 최소 입력

다음 네 가지면 첫 연결 시험을 시작할 수 있다.

1. 실제 사용할 카메라를 PC에 연결한다.
2. Windows 장치 이름 또는 카메라 모델명을 기록한다.
3. 사용할 해상도와 frame rate를 확인한다.
4. 같은 카메라로 다음 10~20초 영상을 각각 하나씩 녹화한다.
   - 사람이 없는 장면
   - 사람이 휠체어 진행 방향을 가로지르는 장면
   - 사람이 휠체어와 같은 방향으로 앞에서 움직이는 장면

카메라 위치·각도·높이는 녹화와 실제 시연 사이에 바꾸지 않는다. 아직 값을 제품 요구사항으로
확정하지 않으며, 측정된 시험 조건으로만 기록한다.

## 기존 경로 코드에 넘겨야 하는 정보

카메라 또는 별도 인식 영역은 기존 경로 코드에 원본 영상이나 정답 위치를 직접 넘기지 않는다.
현재 연구 계약의 `DynamicObservationFrame`과 `ActorTrack`에 대응하는 다음 정보가 필요하다.

- frame 출처와 순번
- 촬영 시각과 전달 시각
- 지도·장면 식별자와 revision
- 사람별 임시 track ID
- 현재 추정 위치와 속도
- 위치·속도 불확실성
- 현재 frame에 track이 없는 경우와 frame 자체가 오지 않은 경우의 구분

필드명·전송 방식·카메라 좌표에서 지도 좌표로 바꾸는 방법은 실제 장비와 인식 영역이 정해진
뒤 별도 계약으로 정한다. 이번 문서는 제품 인터페이스를 확정하지 않는다.

## 첫 연결 시험 순서

1. 장치 열기와 frame timestamp의 단조 증가를 확인한다.
2. 빈 영상·횡단 영상·같은 방향 영상에서 frame 누락과 지연을 기록한다.
3. 사람 검출과 동일 사람 track 유지 여부를 확인한다.
4. 카메라 좌표를 휠체어 또는 지도 평면 좌표로 바꿀 근거를 확인한다.
5. 변환된 track을 기존 observation validator에 넣는다.
6. source·sequence·revision·hash·TTL 거부 시험을 통과시킨다.
7. 입력 상실 시 이동하지 않고 보호정지를 유지하는지 확인한다.
8. 위 항목을 통과한 뒤에만 공개 횡단·같은 방향 장면의 경로 하네스에 연결한다.

## 실패 시 동작

다음 중 하나라도 발생하면 `ActorTrack`을 만들어 이동 근거로 사용하지 않는다.

- 장치 또는 frame 없음
- timestamp·sequence 역행
- 카메라 위치나 보정 상태 변경
- 사람 track ID의 근거 없는 교체
- 위치·속도 또는 불확실성 산출 불가
- 지도 좌표 변환 불가
- 오래된 frame, 누락 frame 또는 출처 불일치
- 빈 frame의 가시영역·가림 범위를 설명할 수 없음

이때 경로 하네스의 결과는 출발 금지 또는 보호정지 유지다. 과거 fresh EMPTY로 미래에 사람이
없음을 보증하지 않는다.

## 완료 기준

이 Gate는 실제 카메라와 녹화 자료를 받은 뒤 아래 결과가 모두 있어야 완료된다.

- 실제 장치·capture mode·고정 설치 조건 기록
- 원본 frame timestamp와 누락률 기록
- 빈 장면·횡단·같은 방향 영상의 재현 가능한 입력
- track 좌표·속도·불확실성의 산출 근거
- 기존 observation validator의 정상·오류 입력 결과
- 입력 상실 시 비영점 이동 명령 `0`

실제 사람 탑승 안전, 제품 카메라 선정, 의료기기 적합성과 R6·hidden은 이 Gate의 완료 기준이
아니다.
