# 초음파 관측 전환 명세 초안

- 작성일: `2026-08-16`
- 상태: 문서 기준선, 하드웨어 사양 입력 대기
- 현재 코드 변경: 없음
- 제품 센서 채택: 아님
- 관련 결정: [ADR 0015](../../decisions/0015-ultrasonic-observation-boundary.md)

## 1. 목적

기존 합성 `ActorTrack` 실험과 실제 Arduino·초음파 거리 관측 사이에 필요한 변환 경계를
정의한다. 기존 경로·DWB·prediction·shared safety gate를 다시 설계하는 문서가 아니다.

## 2. 현재까지 유지하는 결과

- 원본 R2-B 내부 출현 실패 장면과 hard failure는 음성 회귀로 보존한다.
- 감시 진입 파생 world의 Ideal containment miss `38/22 → 0/0`은 추상 상위 계약으로 유지한다.
- 이미 추적하던 Actor의 관측 상실 뒤 정지·새 session·새 허가 복구 결과를 유지한다.
- fresh `EMPTY`, 장애물 소실, 통신 복구만으로 재출발하지 않는다.
- DWB·RPP·경로 reference·안전거리·정지 권한 결과를 초음파 사양 미정 때문에 폐기하지 않는다.

## 3. 새 입력 계층 후보

원시 관측은 최소한 다음 의미를 가져야 한다. 실제 필드명과 통신 형식은 팀 합의 뒤 정한다.

| 정보 | 의미 |
|---|---|
| 센서 식별자 | 어느 방향·장착 위치에서 나온 값인지 구분 |
| source·장착 revision | 다른 차체·배치·설정의 값 혼합 방지 |
| sequence·측정 시각 | 역행·중복·오래된 값 판정 |
| 거리 | 센서 축 또는 빔 안에서 얻은 유효 거리 |
| 상태 | 유효, 무응답, timeout, 범위 밖, 장치 오류 등의 구분 |
| 품질 정보 후보 | 펌웨어가 제공할 수 있을 때만 사용하며 값은 미정 |

`no echo`는 `장애물 없음`과 동일하지 않다. 흡음·경사면·범위 밖·배선 또는 센서 오류도
가능하므로 원인을 판별할 수 없으면 판단 불충분으로 닫는다.

## 4. 추상 처리 흐름

```text
Arduino/초음파 거리 표본
→ source·sequence·시각·상태 검증
→ 센서별 거리 이력
→ 정지에 충분한 점유/접근 증거 또는 판단 불충분
→ 선택적으로 다중 센서·시간 이력 기반 2차원 track
→ 기존 Actor prediction 또는 보수적 점유 영역
→ shared safety gate
```

정지 전용 최소안과 동적 추적 확장안을 구분한다.

- 최소안: 지정 방향 거리와 변화만으로 감속·정지 여부를 판단한다. 2차원 사람 추적이나 우회를
  주장하지 않는다.
- 확장안: 복수 센서와 시간 이력이 충분할 때만 위치·접근 방향·속도 범위를 추정한다. 동일
  물체 결합과 다중 반사체 모호성을 별도 검증한다.

## 5. 먼저 받아야 할 하드웨어 값

구현 또는 수치 시험 전에 다음을 확인한다.

1. Arduino 보드와 초음파 센서 모델
2. 센서 개수, 장착 위치·방향·높이
3. 차체 외곽과 센서 기준 좌표의 관계
4. 실제 측정 주기와 한 주기 안의 센서 구동 순서
5. 유효 거리, blind zone, timeout과 무응답 표현
6. 펌웨어 필터·평균·이상치 제거 여부
7. 여러 센서 동시 사용 시 상호 간섭 방지 방식
8. 정지 명령과 실제 정지 완료를 확인하는 펌웨어 신호

값이 없으면 임의의 HC-SR04 사양이나 인터넷 예제 수치를 제품 요구사항으로 넣지 않는다.

## 6. 후속 공개 시험 순서

1. 고정 벽·박스의 거리 정확도와 무응답 구분
2. 정면 접근·이탈 물체의 거리 변화
3. 좌우 횡단 물체와 센서 경계 진입·이탈
4. 정면·측면·후면 배치별 사각지대
5. 두 물체와 교차 반사·센서 간 간섭
6. frame 누락, stale, sequence 역행, 센서 분리와 재연결
7. 거리 관측만으로 정지하는 최소안
8. 충분한 경우에만 track을 만들어 R2-B·R5-C 공개 장면 재실행

모든 시험은 `측정 불충분 → 정지 유지`를 정상 보수 결과로 구분한다. 실제 센서 하네스가
없는데 합성 거리만으로 하드웨어 통과를 주장하지 않는다.

## 7. 완료조건

- 하드웨어 사양과 장착 배치가 문서에 입력됨
- 무응답과 빈 공간이 구분됨
- stale·invalid·누락 입력이 이동 허가로 바뀌지 않음
- 센서 거리에서 만든 점유 또는 track의 독립 검산이 존재함
- R2-B 내부 출현과 감시 진입 장면에서 관측 가능·불가능 결과가 분리됨
- 초음파 관측 실패가 DWB 또는 경로 알고리즘 실패로 잘못 기록되지 않음
- 실제 센서·축소 실물·사람 안전 증거 범위가 분리됨
