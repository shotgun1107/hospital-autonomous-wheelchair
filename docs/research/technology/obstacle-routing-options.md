# 장애물 대응 기술 후보 메모

- 상태: 미채택 참고 자료
- 작성 계기: 제품 기획보다 앞서 작성된 기술 설계를 보존하기 위한 격리 문서

이 문서는 현재 요구사항이나 아키텍처 결정이 아니다. 프로젝트 기획과 큰 시스템 구성이 완료되기 전에는 구현 지시나 확정 설계의 근거로 사용하지 않는다.

## 앞서 검토된 후보

- 사전 지도 표현 후보: 노드·구간 기반 구조, 격자 기반 구조, 인프라 가이드형 구조
- 대체 경로 계산 후보: A*, Dijkstra 등
- 단기 이동량 추정 후보: 바퀴 엔코더, 관성 센서와 외부 표식의 조합
- 장애물 주변의 제한적 경로 수정 후보: 사전 허용 구역 안의 짧은 우회와 기존 경로 복귀
- 공간 인식 후보: 다중 거리 센서, 2D 거리 스캐너, 깊이 카메라 등
- 내부 경로 관리 후보: 순서화된 실행 목록과 경로 변경 식별자

## 기술 설계에서 나중에 검토할 사항

- 바퀴 기반 이동량 추정은 미끄러짐과 기구 오차가 누적될 수 있으므로 외부 기준 보정 필요성을 검토한다.
- 전방 거리 하나만으로 장애물 양옆의 통과 공간을 판단할 수 있는지 검증한다.
- 장애물 대응은 경로 변경보다 정지가 먼저여야 한다.
- 대체 이동 방법을 찾지 못하거나 위치·센서 정보가 불확실하면 움직이지 않는 실패 동작이 필요하다.
- 실제 감지거리, 정지거리와 안전 여유는 하드웨어 반복 시험으로 정해야 한다.

## 기술 설계 착수 조건

다음 항목이 먼저 합의돼야 한다.

1. MVP의 최종 사용자 흐름과 핵심 시연 장면
2. 대체 경로 선택과 제한적 현재 경로 수정의 포함 범위
3. 병원 지도와 시연 공간이 제공해야 하는 정보
4. 웹·서버·로봇·저수준 제어·물리 안전의 책임 경계
5. 확보 가능한 하드웨어, 예산과 일정

이 조건이 충족된 뒤 후보를 비교하고 ADR로 채택한다.
