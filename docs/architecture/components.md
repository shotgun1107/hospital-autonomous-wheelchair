# 구성 요소와 책임

아래 표는 저장소와 팀 작업을 나누기 위한 큰 영역 초안이다. 보드 배치, 내부 모듈과 기술 선택을 확정하지 않는다.

| 영역 | 책임 |
| --- | --- |
| `clients/web` | 개인 스마트폰용 환자 화면, 대회용 승차장 태블릿·키오스크와 의료진 화면, 환자 지도·의미적 위치, 도움 요청, 환자 버튼·의료진 하차 확인 후보 영역; 코드 분리 여부는 미정 |
| `server` | 목적지 도착 목표시각 예약과 탑승 확인 전 수정·취소, 직접 호출, 대기열·대기 순번·예상 대기시간, 미시작 요청의 의료진 예약 기본 우선과 의료진 순서 변경, 환자별 담당 의료진·병동 알림 대상 연결, 도움 요청·QR 불일치 알림, 탑승 전 취소·빈 차량 재배정, 하차 확인·배터리 조건에 따른 미션 흐름과 상태 이력 |
| `robot` | 자율 이동 판단, 진행 상태, 장애 상황과 승객의 정지·도움 요청 처리 후보 영역 |
| `firmware` | 실제 모터·센서, 자동 하차·배터리 상태 입력과 저수준 제어 후보 영역 |
| `hardware` | 차체, 구동부, 전원과 물리 안전 후보 영역 |
| `contracts` | 큰 책임 경계가 확정된 뒤 정의할 영역 간 계약 |
| `simulation` | 실제 하드웨어 없이 종단 흐름을 확인하기 위한 후보 영역 |
| `tests` | 기능·통합·안전 검증 자료 |

현재의 하위 디렉터리는 역할 분담을 돕기 위한 자리표시자다. `robot/`과 `firmware/`의 실제 책임과 배치는 큰 시스템 구성을 합의한 뒤 확정한다.
