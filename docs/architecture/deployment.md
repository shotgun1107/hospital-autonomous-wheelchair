# 배치 구조

이 문서의 두 구성은 비교 후보일 뿐 채택된 기술 설계가 아니다.

## 공통 기준

- 실제 서비스의 환자 화면은 개인 스마트폰 웹, 대회 MVP의 환자 화면은 승차장 태블릿·키오스크로 제공한다.
- 의료진 화면은 목적지 도착 목표시각 예약과 충돌 요청 순서 선택을 제공한다.
- 화면을 하나의 반응형 코드베이스로 만들지와 서버를 어떤 단위로 나눌지는 아직 결정하지 않는다.
- 대회장 인터넷 의존 여부와 하드웨어 없이 흐름을 시험할 방법은 큰 구성에서 결정한다.

## 후보 A: SBC + MCU

- 상위 연산 장치: 이동 판단과 선택적 영상 처리 후보
- 저수준 제어 장치: 모터와 센서 제어 후보
- 하드웨어 안전 영역: 물리 비상정지 후보

## 후보 B: 단일 MCU

- 이동 판단과 저수준 제어를 하나의 제어 장치에서 처리하는 후보다.
- `robot/`는 사용하지 않거나 호스트 도구만 남긴다.
- 연산량이 큰 후보 기능을 범위에서 줄여야 할 수 있다.

## 미정

- SBC+MCU 또는 단일 MCU 선택
- 보드와 통신 방식
- 서버 실행 장치와 로컬 네트워크 구성
- 영역 사이의 통신 유지·실패 판단 정책
- 배터리·전원 구성과 안전 임계값
