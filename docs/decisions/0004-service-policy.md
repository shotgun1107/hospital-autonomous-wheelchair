# ADR-0004: 호출·예약·대기·탑승 정책

- 상태: 개인 기획 초안 · 팀 합의 전
- 날짜: 2026-08-08

> 세부 운영 규칙의 브레인스토밍 기록이며 현재 구현 기준이 아니다. 큰 틀은 [프로젝트 큰 틀 기준선](../product/big-picture.md)을 따른다.

## 해결하려는 문제

프로젝트는 의료진의 환자 이동 업무 부담을 줄이는 것과 환자가 스스로 이동수단을 호출할 수 있게 하는 것을 동일하게 중요한 목표로 둔다.

## 결정

- 의료진 예약과 환자 직접 호출을 모두 제공한다.
- 의료진이 입력하는 예약 시간은 휠체어 출발시각이 아니라 환자의 목적지 도착 목표시각이다.
- 의료진은 환자의 탑승 확인 전까지 자신이 만든 예약의 목적지와 도착 목표시각을 수정할 수 있다.
- 의료진은 환자의 탑승 확인 전까지 자신이 만든 예약을 취소할 수 있다.
- 미시작 예약과 직접 호출이 충돌하면 의료진 예약을 기본 우선 처리하고, 의료진은 필요하면 미시작 요청의 처리 순서를 바꿀 수 있다. QR 탑승 확인 뒤 시작된 승객 운행은 중단하거나 재배정하지 않는다.
- 한 대의 휠체어가 사용 중이면 새 요청을 대기열에 등록하고 대기 순번과 예상 대기시간을 표시한다.
- 환자는 휠체어가 승차 지점으로 이동 중이더라도 QR 탑승 확인 전까지 자신의 요청을 취소할 수 있다.
- 실제 서비스의 환자 직접 호출은 개인 스마트폰 웹을 목표로 한다.
- 대회 MVP의 환자 직접 호출은 승차장 태블릿·키오스크로 제공한다.
- 탑승 대상과 미션은 QR로 확인하며, 대회 MVP는 고정된 모형 QR을 사용한다.
- 목적지 운행이 끝난 빈 휠체어는 대기 위치로 자동 복귀한다.
- 대회 3분 시연은 환자 직접 호출의 물리 운행을 중심으로 구성한다.
- 관제에는 미션, 목적지, 의미적 위치, 진행 상태와 정지 이유를 표시하고 정밀 실시간 좌표는 필수로 요구하지 않는다.

## 이후에 결정할 세부사항

- 목적지 도착 목표시각을 만족시키기 위한 출발시각 산정 방식
- 의료진 예약 기본 우선, 목표 도착시각, 현재 운행과 장기 대기를 함께 반영하는 세부 스케줄링 방식
- 수정 시점에 빈 휠체어가 이미 이동 중일 때 사용자에게 보여줄 안내
- 예상 대기시간 산정 정책
- 스마트폰 웹과 승차장 태블릿·키오스크 화면의 코드 구성
- 병원 팔찌·환자 QR과 앱 QR을 미션에 연결하는 실제 병원 시스템 연동 방식
- 자동 하차 확인에 사용할 센서·판정 기준과 환자 버튼·의료진 확인의 세부 화면·절차

위 항목은 서비스 정책을 바꾸지 않는 범위에서 이후 큰 구성과 기술 설계 단계에서 결정한다.

환자 부재, 지연, 대기 취소와 움직이는 사람의 운영 정책은 [ADR-0005](0005-operational-exceptions.md)를 따른다.
하차 확인, 취소된 빈 차량 재배정과 배터리 정책은 [ADR-0006](0006-alighting-reassignment-and-battery.md)을 따른다.
도움 요청, 화면 정보와 실제 서비스 QR 정책은 [ADR-0007](0007-help-ui-and-identification.md)을 따른다.
이용 대상, 의료진 예약 취소, 접근성과 운영정보 노출 정책은 [ADR-0008](0008-eligibility-cancellation-and-visibility.md)을 따른다.
