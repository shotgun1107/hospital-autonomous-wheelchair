# ADR-0002: 상위 제어와 펌웨어 배치

- 상태: 제안됨
- 날짜: 2026-08-08

이 ADR은 큰 시스템 구성 단계에서 검토할 후보이며 현재 선택된 배치가 아니다.

## 결정할 문제

상위 이동 판단과 미션 실행을 별도 연산 장치의 `robot/`에서 수행할지, 단일 제어 장치의 `firmware/`에서 수행할지 결정해야 한다.

## 후보 A: SBC + MCU

- 장점: 상위 이동 판단과 저수준 모터 제어의 책임을 나누기 쉽다.
- 단점: 전원과 통신 구조가 복잡해지고 통합 실패 지점이 늘어난다.
- 선택 조건: 두 종류의 장치를 확보할 수 있고 분리로 얻는 이점이 통합 부담보다 큰 경우.

## 후보 B: 단일 MCU

- 장점: 전원과 통신 구조가 단순하고 조기에 실제 주행을 검증하기 쉽다.
- 단점: 연산·메모리 제약으로 일부 자율주행 기능을 축소해야 할 수 있다.
- 선택 조건: 단순성이 더 중요하고 한 장치에서 필요한 기능을 감당할 수 있는 경우.

## 결정 기준

1. 확보된 보드와 센서
2. 전원·통신 안정성
3. 최종 MVP 기능 범위
4. 팀원의 개발·통합 경험
5. 일정 안에 종단 시스템을 만들 수 있는 구성

결정 전까지 `robot/`과 `firmware/`를 모두 보존하되 실제 코드를 중복 구현하지 않는다.
