# ADR-0005: 환자 부재·지연·취소 정책

- 상태: 개인 기획 초안 · 팀 합의 전
- 날짜: 2026-08-08

> 환자 부재·지연·취소의 후보 정책을 보존한 문서이며 현재 구현 기준이 아니다. 큰 틀은 [프로젝트 큰 틀 기준선](../product/big-picture.md)을 따른다.

## 결정

- 의료진 예약으로 휠체어가 승차 지점에 도착했는데 환자가 없으면 의료진에게 보고하고 요청을 종료한 뒤 대기 위치로 자동 복귀한다.
- 승차장 직접 호출의 환자가 없으면 기본 3분 동안 대기하고 소리로 호출한다. 계속 나타나지 않으면 요청을 종료하고 대기 위치로 자동 복귀한다. 대회 시연에서는 10초로 축약한다.
- 목적지 도착 목표시각 지연이 예상되면 의료진에게 알리되 운행은 계속한다.
- 환자는 휠체어가 승차 지점으로 이동 중이더라도 QR 탑승 확인 전까지 자신의 요청을 취소할 수 있다.
- 의료진도 환자의 탑승 확인 전까지 자신이 만든 예약을 취소할 수 있다.
- 취소 당시 승객이 없는 휠체어는 다음 요청이 있으면 해당 승차 지점으로 재배정하고, 없으면 대기 위치로 복귀한다.
- QR 탑승 확인 뒤의 승객 운행은 이 취소 정책으로 중단하지 않는다.
- 움직이는 사람은 별도 기능이 아니라 장애물 상황으로 처리한다. 먼저 정지한 뒤 기존 장애물 대응 정책 안에서 기다림 또는 다른 이동 방법을 판단한다.
- 대회 MVP의 QR은 실제 발급 시스템을 구현하지 않고 고정된 모형 QR을 사용한다.

## 미결정

- 직접 호출 환자 부재 시 소리 알림 형태와 반복 횟수
- 실제 서비스 QR의 발급·표시·인식 흐름
- 최종 시연 목적지 수

구체적인 감지·판단 기술과 임계값은 기술 설계 단계에서 결정한다.
