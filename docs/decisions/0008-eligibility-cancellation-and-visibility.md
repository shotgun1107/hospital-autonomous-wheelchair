# ADR-0008: 이용 대상·의료진 취소·운영정보 노출 정책

- 상태: 개인 기획 초안 · 팀 합의 전
- 날짜: 2026-08-08

> 이용 대상·취소·접근성·운영정보의 후보 정책을 보존한 문서이며 현재 구현 기준이 아니다. 큰 틀은 [프로젝트 큰 틀 기준선](../product/big-picture.md)을 따른다.

## 해결하려는 문제

의료진 예약과 환자 직접 호출의 이용 대상, 의료진이 만든 예약의 취소 범위, 환자별 접근성과 청소·충전·정비 정보를 어디까지 다룰지 정한다.

## 결정

- 의료진 예약과 환자 직접 호출은 모두 보호자나 의료진의 직접 승하차 도움 없이 스스로 승하차할 수 있는 비응급 환자를 대상으로 한다.
- 의료진은 환자의 탑승 확인 전까지 자신이 만든 예약을 취소할 수 있다.
- 취소 시 빈 휠체어가 이미 승차 지점으로 이동 중이면 다음 미시작 요청이 있을 때 해당 요청으로 재배정하고, 없으면 대기 위치로 복귀한다.
- 탑승 확인 뒤 시작된 승객 운행은 이 취소 정책으로 중단하지 않는다.
- 실제 서비스의 화면·음성 안내는 환자별 시력·청력·인지 상태와 선호에 맞춘 개인별 접근성 설정을 목표로 하되, 구체적인 방식은 이후 설계에서 정하고 대회 MVP에서는 개인별 프로필을 구현하지 않는다.
- 청소·충전·정비 운영 상태 관리는 대회 MVP에서 제외한다. 기존의 출발 전 배터리 운행 가능 여부 확인은 유지한다.
- 실제 서비스에서 일반 환자에게는 휠체어의 이용 가능 여부와 예상 대기시간만 보여주고, 청소·정비 같은 내부 사유는 기본적으로 노출하지 않는다.

## 이후에 결정할 세부사항

- 환자별 접근성 설정 항목과 환자 정보에서 설정을 가져오는 방식
- 실제 서비스의 청소·충전·정비 상태를 누가 관리하고 상세 사유를 누가 볼 수 있는가
- 의료진 예약 취소가 대기 환자의 예상 대기시간에 반영되는 방식

이 결정은 실제 병원의 환자 적합성 판단이나 운영자 권한 체계를 검증했다는 의미가 아니다.
