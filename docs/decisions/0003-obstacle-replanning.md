# ADR-0003: 장애물 대응 기능 의도

- 상태: 상위 기능 의도만 채택
- 날짜: 2026-08-08

## 배경

단순히 장애물 앞에서 멈추고 사람이 다시 출발시키는 기능만으로는 사용자가 구상한 자율 이동 보조의 기술성과 시연 의도를 충분히 보여주기 어렵다. 사용자는 현재 경로 일부를 수정하거나 전체 이동 경로를 다시 구성하는 기능이 필요하다고 판단했다.

## 채택한 기능 의도

- 장애물을 감지하면 다른 판단보다 먼저 안전하게 정지한다.
- 전체 대체 경로 선택 또는 제한적 현재 경로 수정으로 가능한 이동 방법을 찾는 기능을 둔다.
- 안전한 방법이 있으면 기존 요청과 목적지를 유지한 채 이동을 계속한다.
- 방법이 없거나 안전성을 판단할 수 없으면 정지 상태를 유지하고 사람에게 알린다.
- 두 방식 중 무엇을 구현할지 또는 둘 다 구현할지는 최종 기능 범위를 정할 때 판단한다.

## 아직 채택하지 않은 기술 설계

- 지도와 경로의 데이터 구조
- 현재 위치와 이동량 추정 방식
- 대체 경로 또는 국소 경로 수정 알고리즘
- 센서와 제어 장치 구성
- 내부 상태 이름, 통신 필드와 안전 임계값

앞서 검토한 구체적인 후보는 [장애물 대응 기술 후보 메모](../research/technology/obstacle-routing-options.md)에 격리했다. 프로젝트 기획과 큰 시스템 구성이 완료된 뒤 비교·검증을 거쳐 별도 ADR로 채택한다.
