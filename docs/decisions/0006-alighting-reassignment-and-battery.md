# ADR-0006: 하차 확인·빈 차량 재배정·배터리 정책

- 상태: 개인 기획 초안 · 팀 합의 전
- 날짜: 2026-08-08

> 하차·재배정·배터리의 후보 정책을 보존한 문서이며 현재 구현 기준이 아니다. 큰 틀은 [프로젝트 큰 틀 기준선](../product/big-picture.md)을 따른다.

## 하차 확인

- 목적지에서는 센서를 이용한 자동 하차 확인을 우선한다.
- 센서 판단이 불확실하거나 자동 확인을 사용할 수 없으면 환자가 `하차 완료` 버튼을 누른다.
- 환자 확인도 불가능하면 의료진이 하차 완료를 확인한다.
- 하차 완료가 확인되기 전에는 빈 차량 자동 복귀를 시작하지 않는다.
- 사용할 센서와 판정 기준은 기술 설계에서 결정한다.

## 탑승 전 취소와 빈 차량 재배정

- 환자는 휠체어가 승차 지점으로 이동 중이더라도 QR 탑승 확인 전까지 요청을 취소할 수 있고, 의료진도 환자의 탑승 확인 전까지 자신이 만든 예약을 취소할 수 있다.
- 취소된 휠체어에 승객이 없고 처리할 다음 예약·직접 호출이 있으면 해당 요청의 승차 지점으로 재배정한다.
- 처리할 다음 요청이 없으면 대기 위치로 자동 복귀한다.
- QR 탑승 확인 뒤의 승객 운행은 이 정책으로 중단하지 않는다.

## 배터리

- 새 미션을 출발하기 전에 배터리가 해당 운행을 시작할 수 있는 상태인지 확인한다.
- 출발 조건을 만족하지 못하면 새 미션을 시작하지 않는다.
- 승객 운행 중 일반 저전력이 확인되면 현재 목적지까지 운행을 완료하고 하차 후 대기 위치로 복귀하며 새 미션을 받지 않는다.
- 즉시 운행을 계속할 수 없는 임계 전원 문제는 일반 저전력과 구분하여 안전정지한다.
- 일반 저전력과 임계 전원의 판정 기준은 기술 설계에서 결정한다.
